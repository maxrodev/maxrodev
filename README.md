## Proyectos

- **Mi aporte:** bounded context de clima, en backend y frontend, con consumo de una API externa.
- **Tecnologías:** Java, Spring Boot, MySQL, Angular, TypeScript
- **Repositorios:** [Organización AgroTrack](https://github.com/AgroTrack-Project) | [API REST](https://github.com/AgroTrack-Project/web-services)

### VitalTrek
Plataforma web desarrollada en equipo con arquitectura DDD.

- **Tecnologías:** C#, ASP.NET Core, Vue, Pinia, JavaScript

Aplicación web de tres capas (datos, aplicación y presentación) para el curso de Sistemas Operativos. Cada capa se ejecuta en un entorno separado: la base de datos y la capa de aplicación en máquinas virtuales de Azure con Linux.

- **Repositorio:** [NaturaGlow](https://github.com/maxrodev/naturaglow)
